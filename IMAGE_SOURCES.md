# Editorial photographs

The application uses remotely served Unsplash photographs as decorative editorial
imagery, not observations of the selected farm or satellite-derived evidence.
Labels and alternative text make this distinction explicit. A landscape gradient
and textual controls remain usable if a remote photograph is unavailable.

- Landscape: https://images.unsplash.com/photo-1500382017468-9049fed747ef
- Agriculture: https://images.unsplash.com/photo-1500937386664-56d1dfef3854
- Grain: https://images.unsplash.com/photo-1574323347407-f5e1ad6d020b
- Provider license information: https://unsplash.com/license

No photographer identity is asserted without verified metadata. Images are
delivered from the provider with resizing parameters rather than redistributed
as scientific figures or field records.
