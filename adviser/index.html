A real embedding model runs on your device to find relevant, cited agronomy guidance. The detailed farm report uses fresh NASA weather and Soil-IQ calculations. This demo retrieves reviewed guidance; it does not generate free-form crop prescriptions.

First use downloads an open model of about 23 MB plus its inference runtime. It can take a few minutes; later runs use the browser cache. No API key is needed. An English model ranks English questions; the reviewed results and report can be read in Arabic.
